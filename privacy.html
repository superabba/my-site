개인정보처리방침 (Privacy Policy)

시행일: 2026년 9월 28일

economypub(이하 “서비스”)은 운영자 본인의 소셜미디어 계정(Instagram, Threads, YouTube)에 카드뉴스와 짧은 영상을 자동으로 게시하기 위해 운영자가 직접 사용하는 개인용 도구입니다. 서비스는 일반 이용자를 대상으로 하지 않으며, 다른 사람의 개인정보를 수집하지 않습니다.

1. 이용하는 정보

  • 운영자가 Google 로그인으로 허용한 YouTube 권한: 운영자 채널에 영상 업로드(youtube.upload), 운영자 채널 정보와 업로드한 영상의 조회수 확인(youtube.readonly)
  • Instagram·Threads: 운영자 계정에 게시물 게시 및 게시물 성과(조회수 등) 확인

2. 이용 목적

위 정보는 운영자 본인의 계정에 콘텐츠를 게시하고, 게시물의 성과를 확인해 다음 콘텐츠 주제를 정하는 데에만 사용합니다.

3. 보관과 공유

  • 인증 토큰은 운영자의 GitHub 저장소 비밀 설정(Secrets)에 암호화되어 보관되며, 제3자와 공유하거나 판매하지 않습니다.
  • Google 사용자 데이터는 광고, 판매, 신용 평가 등 위 목적 외의 용도로 사용하지 않습니다. 서비스의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
  • YouTube API를 사용하므로 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

4. 권한 철회

Google 계정의 서드파티 앱 및 서비스에서 언제든지 서비스의 접근 권한을 철회할 수 있습니다.

5. 문의

개인정보 관련 문의는 Google OAuth 동의 화면에 표시된 개발자 연락처 이메일로 보내주세요.

English summary: economypub is a personal tool used only by its operator to publish content to the operator’s own Instagram, Threads and YouTube accounts. It uses YouTube upload/read-only scopes solely to upload videos to and read statistics of the operator’s own channel. Tokens are stored as encrypted GitHub repository secrets and are never shared or sold. Use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
