개인정보처리방침 (Privacy Policy)

시행일: 2026년 9월 28일 · 최종 수정: 2026년 9월 28일

economypub(이하 “서비스”)은 운영자 본인의 소셜미디어 계정(Instagram, Threads, YouTube)에 카드뉴스와 짧은 영상을 자동으로 게시하기 위해 운영자가 직접 사용하는 개인용 도구입니다. 서비스는 일반 이용자를 대상으로 하지 않으며, 다른 사람의 개인정보를 수집하지 않습니다.

1. YouTube API 서비스 사용

서비스는 YouTube API 서비스를 사용합니다. 서비스를 이용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google 개인정보처리방침(https://policies.google.com/privacy)이 함께 적용됩니다.

2. 이용하는 정보

  • YouTube(운영자가 Google 로그인으로 허용한 권한): 운영자 채널에 영상 업로드(youtube.upload), 운영자 채널 정보와 업로드한 영상의 조회수 확인(youtube.readonly)
  • Instagram·Threads: 운영자 계정에 게시물 게시 및 게시물 성과(조회수 등) 확인
  • 서비스는 쿠키, 광고 식별자, 기기 정보를 수집하지 않으며, 다른 YouTube 사용자의 정보에 접근하지 않습니다.

3. 이용 목적

위 정보는 운영자 본인의 계정에 콘텐츠를 게시하고, 게시물의 성과를 확인해 다음 콘텐츠 주제를 정하는 데에만 사용합니다.

4. 보관과 공유

  • 인증 토큰은 운영자의 GitHub 저장소 비밀 설정(Secrets)에 암호화되어 보관되며, 제3자와 공유하거나 판매하지 않습니다.
  • 업로드한 영상의 ID와 조회수 기록은 운영자의 GitHub 저장소에 저장되며, 콘텐츠 주제 선정 외의 목적으로 사용하지 않습니다.
  • Google 사용자 데이터는 광고, 판매, 신용 평가 등 위 목적 외의 용도로 사용하지 않습니다. 서비스의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 보관 기간과 삭제

  • YouTube API로 받은 데이터(조회수 등)는 최대 30일 동안만 보관하며, 30일이 지나면 새로 갱신하거나 삭제합니다.
  • 접근 권한을 철회하거나 삭제를 요청하면 저장된 인증 토큰과 YouTube 관련 데이터를 7일 이내에 삭제합니다.
  • 삭제 요청은 아래 문의 연락처로 보내 주세요.

6. 권한 철회

Google 보안 설정 페이지(https://security.google.com/settings/security/permissions)에서 언제든지 서비스의 접근 권한을 철회할 수 있습니다.

7. 문의

개인정보 관련 문의와 삭제 요청은 Google OAuth 동의 화면에 표시된 개발자 연락처 이메일 또는 GitHub 이슈로 보내 주세요.

English summary. economypub is a personal tool used only by its operator to publish content to the operator’s own Instagram, Threads and YouTube accounts. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms), and the Google Privacy Policy (https://policies.google.com/privacy) applies. It uses the youtube.upload and youtube.readonly scopes solely to upload videos to, and read statistics of, the operator’s own channel. No cookies or device data are collected. Tokens are stored as encrypted GitHub repository secrets and are never shared or sold. YouTube API data is kept for at most 30 days and then refreshed or deleted; upon revocation or request, stored tokens and YouTube data are deleted within 7 days. Access can be revoked at https://security.google.com/settings/security/permissions. Use of Google API data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
