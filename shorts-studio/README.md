# 쇼츠 스튜디오

글을 넣으면 **목소리(내레이션) + 배경음악 + 자막 + 배경 화면**이 들어간 세로 영상(유튜브 쇼츠·인스타 릴스, 1080×1920)을 만들어 주는 프로그램입니다.
쓰는 방법은 두 가지이고, 서로 따로 동작합니다.

| | 수동 (이 프로그램 화면) | 매일 자동 (GitHub) |
|---|---|---|
| 하는 일 | 화면에서 주제·글·배경·목소리를 직접 골라 만들고, 원할 때 발행 | 매일 경제 쇼츠 1개를 알아서 만들어 **오전 7시 10분**에 발행 |
| 실행 | 이 폴더의 `실행.bat` (PC) | `.github/workflows/shorts-daily.yml` (PC가 꺼져 있어도 됨) |
| 게시 계정 | 경제주막(@economypub) | 경제주막(@economypub) |

## 실행 방법

1. `실행.bat`을 더블클릭합니다.
   - 처음 한 번은 필요한 프로그램을 설치하느라 몇 분 걸립니다.
2. 브라우저에 화면이 열리면 사용하면 됩니다. 끝낼 때는 검은 창을 닫으세요.

> 컴퓨터에 Python이 없으면 https://www.python.org/downloads/ 에서 설치하세요. 설치할 때 **"Add python.exe to PATH"를 꼭 체크**하세요.

## 만드는 순서

1. **주제와 글**: 셋 중 하나를 고릅니다.
   - **AI 주제 추천**: 종류(일기·정보·동기부여·이야기·리뷰)와 관심사를 넣으면 AI가 주제 6개를 추천하고, 고른 주제로 대본을 씁니다.
   - **주제 직접 입력**: 주제만 적으면 AI가 대본을 씁니다.
   - **내가 쓴 글로**: 직접 쓴 일기나 글을 넣습니다. AI로 다듬을 수도 있고, API 키 없이 그대로 문장 단위로 나눌 수도 있습니다.
2. **대본 확인·수정**: 장면마다 내레이션, 화면 큰 글씨, 배경 사진·영상을 고치거나 순서를 바꿀 수 있습니다.
3. **소리와 화면**: 목소리(여성·남성 3종, 빠르기), 배경음악(자동 생성·내 파일·없음), 배경(**AI 그림(나노바나나)**·자동·내 사진·스톡), 자막 모양, 화질을 고릅니다.
   AI 그림을 고르면 장면마다 내레이션에 맞는 세로 그림을 Gemini 나노바나나로 그려 천천히 움직이는 배경으로 씁니다.
4. **영상 만들기**: 완성된 영상을 바로 보고 내려받을 수 있습니다. 업로드용 제목·설명·해시태그도 함께 나옵니다.

5. **발행** (선택): 완성 화면의 **경제주막 계정에 발행하러 가기**나 왼쪽 메뉴의 **발행**에서 인스타 릴스·스레드·유튜브 쇼츠에 올립니다. 아래 "발행하기" 참고.

만든 영상은 `output` 폴더에 저장되고, 왼쪽 메뉴의 **만든 영상**에서 다시 볼 수 있습니다.
같은 이름으로 자막 파일(`.srt`), 설명·대본(`.txt`), 대본 원본(`.json`)도 저장됩니다.

## 발행하기 (경제주막 @economypub 계정)

만든 영상을 카드뉴스와 **같은 경제주막 계정**의 인스타 릴스·스레드·유튜브 쇼츠에 올립니다.
실제 게시는 카드뉴스 봇 저장소(`superabba/my-site`)의 **쇼츠 발행** 워크플로(`shorts-upload.yml`)가 하고, 이 프로그램에는 GitHub 토큰 하나만 넣으면 됩니다.

```
쇼츠 스튜디오: 영상 고르기 → 문구 확인 → [발행하기]
  └─▶ GitHub: shorts/<ID> 브랜치에 영상·문구 커밋 → '쇼츠 발행' 워크플로 실행
        └─▶ 봇: 경제주막 계정 확인 → 하루 한도 확인 → 릴스·스레드·쇼츠 게시 → shorts-records 브랜치에 결과 기록
              └─▶ 이 프로그램에 게시 링크 표시
```

**카드뉴스 자동 발행은 그대로 계속됩니다.**
- 워크플로·실행 순서 그룹·브랜치가 모두 따로라 서로 기다리거나 막지 않습니다.
- 카드뉴스 기록(이력 DB)에 쓰지 않으므로 카드뉴스의 하루 1번 게시 일정이 바뀌지 않습니다.
- 카드뉴스 계정 토큰은 읽기만 하고 갱신하지 않습니다 (갱신은 기존 카드뉴스 토큰 갱신이 계속 맡음).
- 같은 계정이라 게시 직전에 확인합니다: 계정 아이디가 economypub가 아니면 올리지 않고, 하루 게시 한도에서 카드뉴스 몫(기본 10개)을 남기고, 쇼츠는 플랫폼마다 24시간에 최대 5개까지만 올립니다. 숫자는 저장소 Variables(`SHORTS_RESERVE`, `SHORTS_DAILY_MAX`)로 바꿀 수 있습니다.

**처음 한 번만**
1. 카드뉴스 봇 저장소에 쇼츠 발행 기능(PR)이 병합돼 있어야 합니다.
2. **발행** 화면의 **발행 연결 설정**에서 **video-uploader 설정 가져오기**를 누르거나, 같은 GitHub 토큰(`github_pat_…`, Contents·Actions 'Read and write')을 넣고 **저장하고 연결 확인**.
3. 따로 넣을 계정 값은 없습니다 (카드뉴스에 이미 넣어둔 경제주막 계정 값을 씀).

**발행할 때**
- 제목·설명·캡션·해시태그는 대본에서 자동으로 채워지고, 고칠 수 있습니다. 스톡 영상을 썼으면 출처가 유튜브 설명에 들어갑니다.
- 올릴 곳, 유튜브 공개 범위, 'AI 합성 콘텐츠' 표시를 고르고, 계정 확인에 체크한 뒤 **발행하기**.
- 보통 2~5분 뒤 게시 링크가 나옵니다. 창을 닫아도 게시는 계속되고, 아래 **발행 기록**의 **결과 새로고침**으로 확인할 수 있습니다.
- 실패한 플랫폼은 기록의 **실행 기록 → Re-run jobs**로 그 플랫폼만 다시 올립니다.
- 인스타·스레드용 영상은 20MB 이하로 자동 압축해서 올라갑니다.

## 매일 자동 발행 (오전 7시 10분, 경제주막)

화면에서 하는 수동 작업과 별도로, GitHub에서 매일 경제 쇼츠 1개를 만들어 올립니다 (`shorts/daily.py`, `.github/workflows/shorts-daily.yml`).

```
06:45  cron-job.org가 '매일 자동 쇼츠' 실행 (action=auto)
  → 오늘의 테마 (날마다 돌아감): 경제 뉴스 쉽게 풀기 · 직장인 재테크 · 세금·연말정산 · 투자 기초
                                  · 부동산·청약·전월세 · 소비·절약 꿀팁 · 정부 지원·제도 변화
  → 경제 뉴스·실시간 검색어에서 인기 키워드 하나 고르기 (최근 30일 쇼츠·7일 카드뉴스 주제는 피함)
  → Claude 웹 검색으로 사실 확인 (팩트 시트) → 존댓말 30초 대본
  → 장면마다 나노바나나 그림 → 목소리·자막·배경음악을 넣어 영상
07:10  경제주막 계정의 인스타 릴스·스레드·유튜브 쇼츠에 게시 (계정 확인·카드뉴스 몫 남기기·하루 상한 적용)
```

- **같은 내용의 네이버 블로그 글**도 함께 만듭니다 (`shorts/blog.py`, 카드뉴스 `blog.json`과 같은 형식: 소제목 4~5개·자주 묻는 질문·참고 자료, 사진은 영상 표지 + 장면별 나노바나나 그림).
  영상이 게시되면 `shorts-records` 브랜치의 `blog/<영상 ID>/`에 저장되고, **07:20 Claude 루틴 '쇼츠 블로그 글 → 네이버 자동 발행'**(예비 12:20)이 Uplika로 경제주막 네이버 블로그('경제' 카테고리)에 공개 발행합니다. 카드뉴스 블로그 루틴(15:20·19:20)과 같은 방식입니다.
  네이버 글은 PC의 Edge(Uplika 확장)가 대신 쓰므로, 그 시각에 Edge가 꺼져 있으면 다음에 켤 때 올라갑니다. 블로그 글을 끄려면 Variables `SHORTS_BLOG=false`.
- 오늘 이미 게시했거나 오전 6시~낮 12시대가 아니면 건너뛰어, 중복 게시나 늦은 게시가 없습니다.
- 카드뉴스 자동 발행(오후)과 실행·기록이 따로라 서로 영향을 주지 않습니다. 카드뉴스 기록은 겹치는 주제를 피하려고 읽기만 합니다.
- 게시 문구 끝에 "정보 제공용이며 투자 권유가 아닙니다" 안내가 붙고, AI 그림을 쓴 날은 유튜브 'AI 합성 콘텐츠'로 표시됩니다.
- 결과는 Actions의 **매일 자동 쇼츠** 실행 요약(주제·대본·팩트 시트)과 이 프로그램의 **발행 → 발행 기록**에서 볼 수 있습니다. 만든 영상은 실행 기록의 아티팩트로 14일간 받을 수 있습니다.

**처음 한 번만**
1. 저장소 **Settings → Secrets and variables → Actions → Secrets**에 `GEMINI_API_KEY`가 있어야 그림을 그립니다 (카드뉴스에 이미 있으면 그대로 사용).
   이미지 생성은 무료 사용량이 없어서 **결제가 연결된 키**여야 합니다 (그림 1장 약 70원, 하루 약 420원). 그림용 키를 따로 쓰려면 `SHORTS_GEMINI_API_KEY`에 넣으세요.
   키가 없거나 결제가 안 돼 있으면 `PIXABAY_API_KEY`(Secrets)가 있을 때 스톡 영상, 없으면 자동 배경으로 만들어 게시는 그대로 진행됩니다.
2. **cron-job.org**에 작업을 하나 추가합니다 (카드뉴스용 작업과 같은 방법):
   - URL: `https://api.github.com/repos/superabba/my-site/actions/workflows/shorts-daily.yml/dispatches`
   - 방식: `POST`, 실행 시각: 매일 **06:45**, 시간대 **Asia/Seoul**
   - 헤더: `Authorization: Bearer <GitHub 토큰>`, `Accept: application/vnd.github+json`
     (토큰은 이 저장소의 Actions 'Read and write' 권한이 있는 fine-grained 토큰. 카드뉴스 작업에 쓰는 토큰을 그대로 써도 됩니다)
   - 본문: `{"ref":"main","inputs":{"action":"auto"}}`
   cron-job.org가 멈춰서 그날 아직 게시하지 못했다면, GitHub 예약(12:00, 늦어질 수 있음)이 예비로 한 번 더 만들어 바로 게시합니다. 이미 게시한 날은 건너뜁니다.
3. (권장) Actions에서 **매일 자동 쇼츠 → Run workflow → action: draft**로 한 번 시험해 보세요. 게시하지 않고 영상만 만들어 아티팩트로 남깁니다.

**바꿀 수 있는 값** (저장소 Variables, 비우면 기본값)

| Variable | 기본값 | 내용 |
|---|---|---|
| `SHORTS_PUBLISH_AT` | `07:10` | 게시 시각 (KST). cron-job.org 실행 시각은 이보다 20~25분 앞으로 |
| `SHORTS_THEMES` | (7개 테마) | 한 줄에 `이름: 설명` 형식으로 바꾸면 그 테마들이 차례로 돌아감 |
| `SHORTS_IMAGE_MODEL` | `gemini-nano-banana-2.1` | `gemini-3-pro-image`(최고 품질, 장당 약 190원), `gemini-3.1-flash-lite-image`(가장 저렴, 1K) |
| `SHORTS_IMAGE_SIZE` | `2K` | `1K`로 하면 그림 비용이 약 1/3 줄지만 덜 선명함 |
| `SHORTS_LENGTH` | `30` | 영상 길이(초) |
| `SHORTS_VOICE` | `ko-KR-SunHiNeural` | `ko-KR-InJoonNeural`, `ko-KR-HyunsuMultilingualNeural` |
| `SHORTS_DAILY_PLATFORMS` | `reels,threads,youtube` | 올릴 곳 |
| `SHORTS_YOUTUBE_PRIVACY` | `public` | `unlisted`, `private` |

수동으로 오늘 것을 바로 만들어 올리려면 **Run workflow → action: publish-now** (테마·주제를 직접 적을 수도 있음).

## 필요한 키 (왼쪽 설정에 입력)

| 키 | 용도 | 없으면 |
|---|---|---|
| Anthropic API 키 | 주제 추천, 대본 쓰기, 글 다듬기 | "내가 쓴 글로 → 그대로 쓰기"만 가능 |
| Gemini API 키 (결제 연결) | 장면 배경 AI 그림 (나노바나나) | 스톡이나 자동 배경으로 만듦 |
| Pixabay API 키 (무료) | 장면에 맞는 스톡 영상·사진 자동 검색 | 자동 배경이나 내 사진으로 만듦 |
| Pexels API 키 (무료, 선택) | Pixabay와 같은 용도 (Pixabay에서 못 찾으면 사용) | 상관없음 |

- Anthropic 키: https://platform.claude.com 에서 발급 (사용한 만큼 요금. 대본 1개에 보통 수십~백 원 수준)
- Pixabay 키: https://pixabay.com 에 무료 가입 → 로그인한 상태로 https://pixabay.com/api/docs/ 에 들어가면 `key` 항목에 내 키가 보입니다.
- Pexels 키: 현재 새 키 발급이 중단된 상태입니다. 이미 키가 있는 경우에만 넣으세요.
- Gemini 키: https://aistudio.google.com 에서 발급하고, 이미지 생성은 무료 사용량이 없으므로 Google Cloud 결제(Billing)를 연결하세요.
  (Google Flow는 웹 화면 전용이라 이 프로그램에서 쓸 수 없어, 같은 나노바나나 모델을 Gemini API로 씁니다.)
- 키는 이 폴더의 `settings.json`에만 저장됩니다. 다른 사람에게 이 파일을 주지 마세요.

## 알아두면 좋은 점

- **목소리**는 Microsoft Edge의 무료 음성을 쓰므로 인터넷 연결이 필요합니다.
- **자동 배경음악**은 프로그램이 직접 합성한 곡이라 저작권 걱정이 없습니다. 더 좋은 음악을 원하면 유튜브 오디오 보관함 같은 무료 음원을 `assets/music` 폴더에 넣거나 화면에서 올리세요.
- **글꼴**을 바꾸고 싶으면 `.ttf` 글꼴(예: 지마켓 산스)을 `assets/fonts` 폴더에 넣으세요. 없으면 카드뉴스 봇의 Pretendard(있을 때), 그다음 맑은 고딕 굵게를 씁니다.
- 1080p 영상은 영상 길이와 비슷한 시간(30초 영상 → 약 30~60초)이 걸립니다. 확인용으로는 화질을 "빠른 미리보기"로 두면 훨씬 빠릅니다.
- 스톡 영상·사진은 Pixabay/Pexels의 무료 라이선스를 따릅니다. 사용한 영상의 출처는 완성 화면의 "배경 영상·사진 출처"와 `.txt` 파일에 적혀 있으니, 업로드할 때 설명란에 같이 적어 주면 좋습니다.
- Pixabay 스톡 영상은 대부분 가로 영상이라, 가운데 부분을 세로로 잘라서 씁니다. 세로 영상이 있으면 그걸 먼저 고릅니다.

```
streamlit_app.py      화면 시작점 (설정 사이드바)
app_pages/            화면: 영상 만들기, 만든 영상, 발행
```
