1. 서비스 개요

economypub(이하 “서비스”)은 운영자가 직접 사용하는 콘텐츠 자동화 도구로, 절약·재테크 정보 카드뉴스와 짧은 영상을 만들어 운영자 본인의 Instagram, Threads, YouTube 채널에 게시합니다. 서비스는 일반 이용자에게 가입이나 로그인 기능을 제공하지 않습니다.

2. YouTube 서비스 약관

서비스는 YouTube API 서비스를 사용합니다. 서비스를 이용하는 사람은 YouTube 서비스 약관(https://www.youtube.com/t/terms)에 동의하고 이를 따라야 합니다. 개인정보 처리에 관해서는 economypub 개인정보처리방침과 Google 개인정보처리방침이 적용됩니다.

3. 이용 범위

  • 서비스는 운영자 본인이 소유한 계정과 채널에만 콘텐츠를 게시합니다.
  • 서비스는 YouTube API 서비스 약관과 개발자 정책을 준수하며, 다른 사용자의 계정이나 데이터에 접근하지 않습니다.

4. 콘텐츠와 책임

게시되는 콘텐츠는 일반적인 정보 제공을 위한 것이며, 금융·법률 자문이 아닙니다. 콘텐츠에 대한 책임은 운영자에게 있습니다.

5. 약관 변경

약관이 변경되면 이 페이지에 게시하고 시행일을 갱신합니다.

6. 문의

문의는 Google OAuth 동의 화면에 표시된 개발자 연락처 이메일 또는 GitHub 이슈로 보내 주세요.
