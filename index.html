economypub · 경제주막

20~40대를 위한 짠테크·절약 정보 카드뉴스와 쇼츠

economypub은 운영자가 직접 사용하는 콘텐츠 자동화 도구입니다. 매일 한 번 절약·재테크 정보를 카드뉴스와 짧은 영상으로 만들어 운영자 본인의 Instagram, Threads, YouTube 채널에 게시합니다. 일반 이용자를 위한 가입·로그인 기능은 없습니다.

YouTube 연동

Developed with YouTube · YouTube API 서비스 사용

  • 운영자 채널 경제주막 (@economypub)에 쇼츠를 업로드합니다.
  • 업로드한 영상의 조회수를 확인해 다음 콘텐츠 주제를 정합니다.
  • YouTube API 서비스를 사용하므로 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
